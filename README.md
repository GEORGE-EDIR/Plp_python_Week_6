# Times Tables, Skip Counting & Loop Hospital

`times_table.py` — asks for a number and prints its times table from 1 to 10.

`skip_counter.py` — prints even numbers from 0 to 20 and counts down from 10 to 0.

`loop_hospital.py` — fixes three common loop problems: incorrect range bounds, an infinite `while` loop, and a misplaced accumulator.

An off-by-one error happens when a loop runs one time too many or one time too few because its start or stop bounds are incorrect. A useful `range()` habit is to remember that the stop value is **not included**, and to check the first and last values your loop should produce.
